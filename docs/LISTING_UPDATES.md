# 服裝與租借流程更新

## 本次新增

- 每件服裝可上傳 1–6 張 JPG、PNG 或 WebP 照片，每張最多 5 MB，合計最多 20 MB。可移除待上傳照片、指定封面，在詳情頁切換相簿。
- 選填服裝原品牌，品牌也納入搜尋。
- 選填 Facebook／Instagram 公開個人頁，商品詳情顯示連結，已接受的租借紀錄也提供出租者社群入口。只接受對應平台的 HTTPS 網址；連結不是平台身分驗證。
- 選填試穿者身高、體重、胸圍、腰圍、臀圍與試穿感受。這些欄位公開，全部可留白；不是服裝平量尺寸或合身保證。
- 租借紀錄顯示各狀態的下一步，區分衣主接受與實際付款。

## 部署與資料

新增 `0002_listing_details.sql`，為既有 items 表新增 details 與 photos 欄位。舊的單張照片商品仍能顯示；無需刪除或重建既有資料。啟動時執行遷移，使用相同 /data Volume。

## 暫未啟用

網站擁有者尚無商家帳號，本版不串接線上付款、押金代收、退款或物流下單。不顯示假的付款完成、付款碼或物流單號。這些功能需要商家設定與實際交易測試後才能推出。

## 驗證

本機測試涵蓋雙照片儲存與讀取、封面順序、超過照片上限、社群錯誤網域、異常身形數值、選填空白欄位、品牌與社群持久化、訂單社群資訊、角色權限、檔期重疊、接受、取消與登出。手機 390px 預览檢查沒有橫向溢出，相簿切換正常。
